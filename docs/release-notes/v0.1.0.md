The first public release of **SIDB**, a personal desktop browser built on Electron 45 (Chromium 156).

## Downloads

| System | File |
|---|---|
| Windows 10/11, 64-bit, installer | `SIDB-0.1.0-Setup.exe` |
| Windows, portable | `SIDB-0.1.0-win-x64.zip` |
| Debian, Ubuntu and relatives | `sidb_0.1.0_amd64.deb` |
| Fedora, openSUSE and relatives | `sidb-0.1.0-1.x86_64.rpm` |
| Other Linux, portable | `SIDB-0.1.0-linux-x64.zip` |

Check a download against `SHA256SUMS.txt`:
Windows `Get-FileHash .\SIDB-0.1.0-Setup.exe -Algorithm SHA256`, Linux `sha256sum -c --ignore-missing SHA256SUMS.txt`.

## What's in it

- Tabs (horizontal or vertical), tab groups, pinning, sleeping background tabs on request, session restore
- Address bar with history, bookmarks and search suggestions
- Private windows that keep nothing after they close
- Profiles, bookmarks (HTML import/export), history, downloads, daily backups
- SIDB Shield: ad and tracker blocking with public filter lists, popup blocking, optional Safe Browsing and secure DNS
- SIDB AI with your own NVIDIA API key
- Themes, accent colours, New Tab page, command palette, QR codes, screenshots, Performance panel
- Update check against GitHub Releases (it tells you; you install)

See the [user guide](https://github.com/siddhantsaurabhjha/SIDB/blob/main/docs/USER_GUIDE.md).

## Known limitations

- **Not code-signed.** Windows SmartScreen shows "Unknown publisher" the first time; choose "More info" > "Run anyway" after checking the checksum.
- **No automatic installation of updates.** SIDB checks GitHub once a day and opens the release page; you run the new installer yourself. Your data is kept.
- **Google Account sign-in does not work inside SIDB.** Google blocks sign-in from browsers built on embedded frameworks. SIDB explains this and offers to continue in your default browser.
- The `.rpm` and the Linux zip were built but not installed in testing; the `.deb` was installed and tested on Ubuntu (CI).
- Not built yet: tab drag-and-drop, a shortcut editor, Picture-in-Picture, Reader mode, third-party cookie blocking.
