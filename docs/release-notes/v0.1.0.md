The first public release of **SIDB**, a personal desktop browser built on Electron 45 (Chromium 156).

## Downloads

| System | File |
|---|---|
| Windows 10/11, 64-bit | `SIDB-0.1.0-win-x64.zip` (portable, no installer) |
| Debian, Ubuntu and relatives | `sidb_0.1.0_amd64.deb` |
| Fedora, openSUSE and relatives | `sidb-0.1.0-1.x86_64.rpm` |
| Other Linux, portable | `SIDB-0.1.0-linux-x64.zip` |

Check a download against `SHA256SUMS.txt`:
Windows `Get-FileHash .\SIDB-0.1.0-win-x64.zip -Algorithm SHA256`, Linux `sha256sum -c --ignore-missing SHA256SUMS.txt`.

**Windows:** unpack the ZIP to a folder you want to keep (for example `C:\Apps\SIDB`) and run `SIDB.exe`. There is no installer, Start menu entry or Apps-list entry in this release; pin `SIDB.exe` to the taskbar if you like. To remove SIDB, delete that folder. Your data lives separately in `%APPDATA%\SIDB` and is kept (delete it yourself if you want it gone).

## What's in it

- Tabs (horizontal or vertical), tab groups, pinning, sleeping background tabs on request, session restore
- Address bar with history, bookmarks and search suggestions
- Private windows that keep nothing after they close
- Profiles, bookmarks (HTML import/export), history, downloads, daily backups
- SIDB Shield: ad and tracker blocking with public filter lists, popup blocking, optional Safe Browsing and secure DNS
- SIDB AI with your own NVIDIA API key
- Themes, accent colours, New Tab page, command palette, QR codes, screenshots, Performance panel
- Update check against GitHub Releases (it tells you; you download the new version yourself)

See the [user guide](https://github.com/siddhantsaurabhjha/SIDB/blob/main/docs/USER_GUIDE.md).

## Known limitations

- **No Windows installer yet.** The Squirrel installer works silently but its normal, visible install did not finish on GitHub's test machines, and I could not show it works on a real desktop. It is planned for v0.1.1. This release uses the portable ZIP instead.
- **Not code-signed.** Windows SmartScreen shows "Unknown publisher" the first time you run `SIDB.exe` (More info > Run anyway, after checking the checksum). Files from a downloaded ZIP may also need "Unblock" in the file's properties.
- **No automatic installation of updates.** SIDB checks GitHub once a day and opens the release page; you download the new version yourself. Your data is kept.
- **Google Account sign-in does not work inside SIDB.** Google blocks sign-in from browsers built on embedded frameworks. SIDB explains this and offers to continue in your default browser.
- The `.deb` was installed and tested on Ubuntu 24.04 (CI). The `.rpm` and the Linux zip were built but not installed or run in testing.
- Linux was tested only on a virtual display in CI, not on a real desktop.
- Not built yet: tab drag-and-drop, a shortcut editor, Picture-in-Picture, Reader mode, third-party cookie blocking.

## Verified for this release

On GitHub's clean Windows and Ubuntu machines: unit and database tests; the smoke test (interface, database, encrypted key storage, Shield blocking and element hiding, website icons, update check, sandboxing, private windows) on the Windows build, on the unpacked Windows ZIP and on the installed `.deb`; and `.deb` install and removal. On the developer's PC: performance and memory-leak run, security audit tests. Details: [progress.md](https://github.com/siddhantsaurabhjha/SIDB/blob/main/progress.md).
